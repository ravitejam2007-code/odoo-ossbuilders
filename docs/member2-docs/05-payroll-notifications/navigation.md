# Phase 5 Navigation — Payroll and Notifications

## Routes
- `/payroll`
- `/notifications`

## Payroll
Employee navigation → Payroll.
The screen is read-only.

## Notifications
Employee navigation → Notifications.
Unread state may be represented in the navigation if returned by the API.

## What NOT to do
Do not create:
- `/payroll/edit`
- `/admin/payroll`
- employee salary-management controls
- admin notification management links
